# قاعدة وكالة تصميم مواقع إلكترونية (للمبتدئين)

مجلد مستقل تمامًا عن باقي هذا المستودع — قاعدة جاهزة لبدء "وكالة" تصميم
مواقع صغيرة وبيعها لأصحاب الأنشطة التجارية، **بدون أي خبرة برمجية سابقة**.

لا تحتاج تثبيت أي شيء (لا npm، لا Node، لا قاعدة بيانات). كل شيء هنا HTML
و CSS و JavaScript عادي يعمل بفتح ملف واحد في المتصفح.

## محتويات هذا المجلد

```
agency-starter/
├── README.md                          ← أنت هنا (الدليل التقني)
├── BUSINESS-GUIDE.md                   ← كيف تجد عملاء وتسعّر وتبني الوكالة
├── templates/                          ← أوراق عمل تُنسخ لكل عميل جديد
│   ├── استبيان-معلومات-العميل.md
│   ├── عرض-سعر-نموذج.md
│   └── عقد-تصميم-موقع-نموذج.md
└── website-template/                   ← القالب نفسه (تُنسخ نسخة لكل عميل)
    ├── index.html
    └── assets/{css,js,img}
```

## 1. جرّب القالب الآن

افتح `website-template/index.html` مباشرة بالضغط عليه مرتين — سيفتح في
متصفحك فورًا. هذا كل ما تحتاجه لرؤية الموقع.

للحصول على تجربة أفضل أثناء التعديل (تحديث تلقائي عند الحفظ)، إن كنت
تستخدم VS Code، ثبّت إضافة **Live Server** مجانًا، ثم اضغط يمين على
`index.html` واختر "Open with Live Server".

## 2. طريقة استنساخ القالب لكل عميل جديد

لا تُعدّل أبدًا على `website-template/` الأصلي مباشرة — هو نسختك "النظيفة"
التي تبدأ منها كل مرة. لكل عميل جديد:

1. أنشئ مجلدًا جديدًا باسم العميل، مثال: `agency-starter/clients/مطعم-الوردة/`
2. انسخ محتوى `website-template/` بالكامل إلى داخله
3. افتح `index.html` داخل النسخة الجديدة، وابحث (Ctrl+F) عن كلمة
   **"غيّر هذا"** — كل تعليق بهذا الشكل يدلّك بالضبط على ما يجب تعديله
   (العنوان، النصوص، الألوان، أرقام التواصل...)
4. استخدم إجابات `templates/استبيان-معلومات-العميل.md` المُعبّأة من العميل
   لملء كل هذه الأماكن

## 3. تغيير ألوان الهوية البصرية

في أول `index.html`، ستجد:

```js
tailwind.config = {
  theme: { extend: { colors: { brand: { 500: '#3b82f6', 600: '#2563eb', ... } } } }
}
```

غيّر قيمة `600` (الأهم) للون هوية العميل (مثال: `#16a34a` للون أخضر)،
واتركه يتدرّج طبيعيًا — أو استخدم أي مولّد "Tailwind color shades" مجاني
على الإنترنت لتوليد الدرجات الفاتحة والغامقة تلقائيًا من لون واحد.

## 4. إضافة صور حقيقية

راجع ملف `website-template/assets/img/ضع-صورك-هنا.txt` — يشرح كيف تضع
صورة حقيقية بدل كل "مكان صورة" رمادي في القالب.

## 5. تفعيل استقبال رسائل نموذج التواصل

الموقع صفحة ثابتة (لا يوجد سيرفر خلفي)، فلا يمكنه إرسال بريد بنفسه. أسهل
حل مجاني للمبتدئ:

1. اذهب إلى [formspree.io](https://formspree.io) وأنشئ حسابًا مجانيًا
2. أنشئ "Form" جديد، وضع بريد العميل الذي سيستقبل الرسائل
3. سيعطيك Formspree رابطًا شكله: `https://formspree.io/f/xxxxxxxx`
4. افتح `assets/js/script.js`، وضع هذا الرابط في المتغيّر:
   ```js
   const ACTION_URL = 'https://formspree.io/f/xxxxxxxx';
   ```
5. جرّب إرسال رسالة من الموقع — ستصل فعليًا لبريد العميل

## 6. نشر الموقع على الإنترنت (مجانًا للتجربة)

أسهل طريقة للمبتدئ هي **Netlify Drop** (بدون حساب أو أوامر):

1. اذهب إلى [app.netlify.com/drop](https://app.netlify.com/drop)
2. اسحب مجلد العميل بالكامل (مثل `clients/مطعم-الوردة/`) وأفلته في الصفحة
3. سيعطيك رابطًا فوريًا مثل `https://xyz123.netlify.app` — هذا موقع حقيقي
   منشور على الإنترنت يمكنك إرساله للعميل للمعاينة

### ربط دومين خاص بالعميل (مثل `restaurant-alwarda.com`)

بعد رضا العميل وشراء دومين (من أي مزوّد مثل Namecheap أو GoDaddy):
1. في لوحة Netlify لموقعه، اذهب إلى **Domain settings → Add custom domain**
2. اتبع التعليمات لتوجيه الدومين (تضيف بعض السجلات في لوحة تحكم الدومين،
   وهي خطوة واحدة بسيطة تشرحها Netlify لك تلقائيًا بالتفصيل)
3. خلال دقائق إلى ساعات، يعمل موقع العميل على دومينه الخاص فعليًا

## 7. مشكلة شائعة: الموقع يظهر بدون تنسيق (بدون ألوان/خطوط)

هذا القالب يحمّل التنسيق (Tailwind) والخط العربي والأيقونات من الإنترنت
مباشرة (CDN) ليبقى بسيطًا بلا أي تثبيت. إذا فتحته وظهر بلا أي تنسيق، تأكد
من أن جهازك متصل بالإنترنت فعليًا (أو أن الشبكة/الجدار الناري لا يحجب
`cdn.tailwindcss.com`، `fonts.googleapis.com`، `cdnjs.cloudflare.com`) ثم
أعد تحميل الصفحة.

## 8. الخطوة التالية

افتح [`BUSINESS-GUIDE.md`](./BUSINESS-GUIDE.md) لتتعلّم كيف تجد أول عملائك،
كيف تسعّر خدماتك، وكيف تدير كل مشروع من البداية للتسليم.
