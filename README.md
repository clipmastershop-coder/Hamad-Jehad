# متجر منتجات رقمية (Next.js + Stripe)

موقع متجر إلكتروني لبيع منتجات رقمية (كتب، قوالب، ملفات...إلخ) مع دفع عبر Stripe
وتسليم فوري للملف بعد تأكيد الدفع برابط تحميل آمن مؤقت (بدون قاعدة بيانات).

## 1. تشغيل المشروع محليًا

```bash
npm install
cp .env.example .env.local
```

افتح `.env.local` وعدّل القيم:

- `STRIPE_SECRET_KEY` و `NEXT_PUBLIC_STRIPE_PUBLISHABLE_KEY`: احصل عليهما من
  [dashboard.stripe.com/apikeys](https://dashboard.stripe.com/apikeys) (ابدأ بمفاتيح test أثناء التجربة).
- `DOWNLOAD_SECRET`: أي نص عشوائي طويل (لتوقيع روابط التحميل بأمان).
- `NEXT_PUBLIC_APP_URL`: `http://localhost:3000` محليًا، ورابط موقعك الحقيقي بعد النشر.

ثم شغّل:

```bash
npm run dev
```

افتح المتصفح على `http://localhost:3000`.

## 2. إضافة منتجاتك الخاصة

كل منتجاتك موجودة في ملف واحد: `lib/products.ts`. لإضافة منتج جديد:

1. ضيف عنصر جديد في مصفوفة `products` (اسم، سعر بالسنت، وصف، صورة).
2. ضع صورة المنتج في `public/images/`.
3. ضع الملف الرقمي الحقيقي (PDF, ZIP...) داخل مجلد `digital-products/`
   (هذا المجلد **غير متاح للعامة إطلاقًا** — لا يمكن تحميل الملف إلا بعد الدفع).
4. اربط `fileName` في المنتج باسم الملف الذي وضعته.

## 3. كيف تتم عملية البيع؟

1. العميل يفتح صفحة المنتج ويضغط "اشتر الآن".
2. يتم تحويله إلى صفحة دفع Stripe الرسمية (آمنة ومرخّصة).
3. بعد الدفع، يرجع لصفحة `/success`، والموقع يتأكد من Stripe أن الدفع تم بنجاح
   فعليًا قبل توليد رابط تحميل.
4. رابط التحميل موقّع رقميًا (HMAC) ومحدود بـ 24 ساعة — لا يمكن تخمينه أو مشاركته
   كرابط صالح للأبد.

## 4. النشر (Deploy) على الإنترنت

أسهل طريقة: [Vercel](https://vercel.com) (مجاني للمشاريع الصغيرة):

1. ارفع المشروع على GitHub (تم بالفعل في هذا الريبو).
2. من Vercel: New Project → اختر الريبو.
3. أضف متغيرات البيئة نفسها الموجودة في `.env.example` من إعدادات المشروع في Vercel.
4. بعد أول نشر، فعّل مفاتيح Stripe **الحقيقية (live)** بدل test، وحدّث
   `NEXT_PUBLIC_APP_URL` برابط موقعك الحقيقي.

## 5. ملاحظات أمان مهمة

- لا تضع أبدًا `STRIPE_SECRET_KEY` في كود يظهر للمتصفح — هو موجود فقط في السيرفر (API routes).
- الملفات داخل `digital-products/` لا يصل لها أحد مباشرة؛ التحميل يتم فقط عن طريق
  API يتحقق من توكن موقّع صادر بعد تأكيد الدفع من Stripe.
- غيّر `DOWNLOAD_SECRET` لقيمة عشوائية فعلية قبل النشر على الإنترنت.
