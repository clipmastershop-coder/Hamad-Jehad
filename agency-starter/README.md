# قاعدة وكالة تصميم مواقع إلكترونية (للمبتدئين)

مجلد مستقل تمامًا عن باقي هذا المستودع — قاعدة جاهزة لبدء "وكالة" تصميم
مواقع صغيرة وبيعها لأصحاب الأنشطة التجارية، **بدون أي خبرة برمجية سابقة**.

لا تحتاج تثبيت أي شيء (لا npm، لا Node، لا قاعدة بيانات). كل شيء هنا HTML
و CSS و JavaScript عادي يعمل بفتح ملف واحد في المتصفح.

## محتويات هذا المجلد

```
agency-starter/
├── README.md                          ← أنت هنا (الدليل التقني)
├── BUSINESS-GUIDE.md                   ← كيف تجد عملاء وتسعّر وتبني الوكالة
├── templates/                          ← أوراق عمل تُنسخ لكل عميل جديد
│   ├── استبيان-معلومات-العميل.md
│   ├── عرض-سعر-نموذج.md
│   └── عقد-تصميم-موقع-نموذج.md
├── website-template/                   ← القالب الأساسي (تُنسخ نسخة لكل عميل)
│   ├── index.html
│   └── assets/{css,js,img}
└── website-template-premium/           ← قالب "فاخر" بإحساس آبل (سكرول وحركات)
    ├── index.html
    └── assets/{css,js,img}
```

يوجد قالبان:
- **website-template**: بسيط وسريع، مناسب لغالبية العملاء، بدون أي حركات معقّدة
- **website-template-premium**: طباعة ضخمة، سكرول ناعم، تأثيرات حركية مرتبطة
  بالسكرول (إحساس قريب من موقع آبل) — استخدمه للعملاء المستعدين يدفعوا أكثر
  مقابل شكل مميز ومختلف (راجع قسم "القالب الفاخر" بالأسفل)

## 1. جرّب القالب الآن

افتح `website-template/index.html` مباشرة بالضغط عليه مرتين — سيفتح في
متصفحك فورًا. هذا كل ما تحتاجه لرؤية الموقع.

للحصول على تجربة أفضل أثناء التعديل (تحديث تلقائي عند الحفظ)، إن كنت
تستخدم VS Code، ثبّت إضافة **Live Server** مجانًا، ثم اضغط يمين على
`index.html` واختر "Open with Live Server".

## 2. طريقة استنساخ القالب لكل عميل جديد

لا تُعدّل أبدًا على `website-template/` الأصلي مباشرة — هو نسختك "النظيفة"
التي تبدأ منها كل مرة. لكل عميل جديد:

1. أنشئ مجلدًا جديدًا باسم العميل، مثال: `agency-starter/clients/مطعم-الوردة/`
2. انسخ محتوى `website-template/` بالكامل إلى داخله
3. افتح `index.html` داخل النسخة الجديدة، وابحث (Ctrl+F) عن كلمة
   **"غيّر هذا"** — كل تعليق بهذا الشكل يدلّك بالضبط على ما يجب تعديله
   (العنوان، النصوص، الألوان، أرقام التواصل...)
4. استخدم إجابات `templates/استبيان-معلومات-العميل.md` المُعبّأة من العميل
   لملء كل هذه الأماكن

## 3. القالب الفاخر (إحساس آبل)

`website-template-premium/` نفس فكرة الاستنساخ والتعديل بالضبط (قسم 2
أعلاه)، بس بتصميم مختلف: طباعة ضخمة، خلفيات تتبدّل بين فاتح وغامق، وتأثيرات
حركية (GSAP + ScrollTrigger + Lenis) تتفاعل مع السكرول — قسم "الفكرة" مثلاً
يثبّت الصفحة وتتكبّر الصورة أثناء تمريرك، والأرقام بقسم "الأرقام" تتعدّ من
صفر للرقم الحقيقي تلقائيًا.

- يحتاج نفس خطوات التعديل (ابحث عن "غيّر هذا")، ونفس طريقة تغيير اللون
  (قسم 4 بالأسفل) ونفس طريقة النشر (قسم 7)
- أثقل شوي بسبب مكتبات الحركة الإضافية (لسه بدون أي تثبيت، كل شيء CDN)
- استخدمه كـ"باقة شاملة" أغلى سعرًا (راجع التسعير بـ`BUSINESS-GUIDE.md`)
  — هو نفسه نقطة بيع: "موقعك هيكون بإحساس شركات عالمية زي آبل"
- صورة قسم "الفكرة" لازم تكون عالية الجودة (1600px+ عرضًا على الأقل) لأنها
  تتكبّر أثناء السكرول وأي صورة صغيرة هتظهر مبكسلة

## 4. تغيير ألوان الهوية البصرية

في أول `index.html`، ستجد:

```js
tailwind.config = {
  theme: { extend: { colors: { brand: { 500: '#3b82f6', 600: '#2563eb', ... } } } }
}
```

غيّر قيمة `600` (الأهم) للون هوية العميل (مثال: `#16a34a` للون أخضر)،
واتركه يتدرّج طبيعيًا — أو استخدم أي مولّد "Tailwind color shades" مجاني
على الإنترنت لتوليد الدرجات الفاتحة والغامقة تلقائيًا من لون واحد.

## 5. إضافة صور حقيقية

راجع ملف `website-template/assets/img/ضع-صورك-هنا.txt` — يشرح كيف تضع
صورة حقيقية بدل كل "مكان صورة" رمادي في القالب.

## 6. تفعيل استقبال رسائل نموذج التواصل

الموقع صفحة ثابتة (لا يوجد سيرفر خلفي)، فلا يمكنه إرسال بريد بنفسه. أسهل
حل مجاني للمبتدئ:

1. اذهب إلى [formspree.io](https://formspree.io) وأنشئ حسابًا مجانيًا
2. أنشئ "Form" جديد، وضع بريد العميل الذي سيستقبل الرسائل
3. سيعطيك Formspree رابطًا شكله: `https://formspree.io/f/xxxxxxxx`
4. افتح `assets/js/script.js`، وضع هذا الرابط في المتغيّر:
   ```js
   const ACTION_URL = 'https://formspree.io/f/xxxxxxxx';
   ```
5. جرّب إرسال رسالة من الموقع — ستصل فعليًا لبريد العميل

## 7. نشر الموقع على الإنترنت (مجانًا للتجربة)

أسهل طريقة للمبتدئ هي **Netlify Drop** (بدون حساب أو أوامر):

1. اذهب إلى [app.netlify.com/drop](https://app.netlify.com/drop)
2. اسحب مجلد العميل بالكامل (مثل `clients/مطعم-الوردة/`) وأفلته في الصفحة
3. سيعطيك رابطًا فوريًا مثل `https://xyz123.netlify.app` — هذا موقع حقيقي
   منشور على الإنترنت يمكنك إرساله للعميل للمعاينة

### ربط دومين خاص بالعميل (مثل `restaurant-alwarda.com`)

**الخطوة أ) شراء الدومين — ومن يشتريه مهم جدًا**

اشرح للعميل أن الدومين يُسجَّل سنويًا (عادة 10-15 دولار/سنة) من مزوّدين مثل:
- [Namecheap](https://namecheap.com) — سهل وواضح للمبتدئين
- [Cloudflare Registrar](https://domains.cloudflare.com) — أرخص سعر عادة (بدون هامش ربح)
- GoDaddy — منتشر لكن أغلى قليلًا وتسويقه مزعج أحيانًا

⚠️ **قاعدة مهمة لحماية العميل (ونفسك من المشاكل لاحقًا)**: اجعل العميل هو
من يسجّل الدومين **باسمه وبطاقته وبريده الخاص** (أنت تساعده فقط في
الاختيار والخطوات). لو سجّلته أنت باسمك "لتسهيل الأمور"، يصبح الدومين
ملكك قانونيًا لا ملك العميل — وهذا يسبب نزاعات شهيرة بين وكالات وعملائها
عند الخلاف لاحقًا. استثناء وحيد مقبول: لو اتفقتما كتابيًا أنك تدير كل شيء
مقابل اشتراك شهري تملك فيه الدومين طوال مدة الاشتراك فقط.

**الخطوة ب) ربط الدومين بالموقع المنشور على Netlify**

1. في لوحة Netlify لموقع العميل، اذهب إلى **Domain settings → Add a domain**
2. اكتب الدومين الذي اشتراه العميل
3. Netlify تعطيك إما: (أ) عنوانين IP/CNAME تضيفهما في لوحة تحكم الدومين
   عند المزوّد (Namecheap مثلًا)، أو (ب) تطلب تغيير "Nameservers" بالكامل
   لتُدار من Netlify مباشرة (أسهل وأقوى، لكن يعني كل إعدادات الدومين
   تدار من Netlify بعدها)
4. SSL (القفل الأخضر https) يُفعَّل تلقائيًا ومجانًا من Netlify خلال دقائق
   — نقطة بيع ممتازة تذكرها للعميل: "موقعك آمن ومشفّر بدون أي تكلفة إضافية"
5. خلال دقائق إلى 24 ساعة كحد أقصى (انتشار DNS)، يعمل الموقع على الدومين

## 8. مشكلة شائعة: الموقع يظهر بدون تنسيق (بدون ألوان/خطوط)

هذا القالب يحمّل التنسيق (Tailwind) والخط العربي والأيقونات من الإنترنت
مباشرة (CDN) ليبقى بسيطًا بلا أي تثبيت. إذا فتحته وظهر بلا أي تنسيق، تأكد
من أن جهازك متصل بالإنترنت فعليًا (أو أن الشبكة/الجدار الناري لا يحجب
`cdn.tailwindcss.com`، `fonts.googleapis.com`، `cdnjs.cloudflare.com`) ثم
أعد تحميل الصفحة. في القالب الفاخر تأكد كمان من عدم حجب
`cdn.jsdelivr.net` (مكتبة Lenis) — لو انحجبت، الموقع يشتغل عادي بس بدون
السكرول الناعم والحركات (مصمّم عمدًا يعمل بدونها لو ما توفرش الإنترنت).

## 9. الخطوة التالية

افتح [`BUSINESS-GUIDE.md`](./BUSINESS-GUIDE.md) لتتعلّم كيف تجد أول عملائك،
كيف تسعّر خدماتك، وكيف تدير كل مشروع من البداية للتسليم.
