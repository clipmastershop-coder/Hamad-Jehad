# ClipMaster — منصة رقمية كاملة (Next.js + SQLite محلي + Stripe)

موقع ClipMaster: منتجات رقمية ودورات واستشارات لأصحاب صالونات الحلاقة، مع
متجر إلكتروني حقيقي (سلة شراء، Checkout، حسابات عملاء، سجل طلبات، تسليم رقمي
آمن) ولوحة تحكم لإدارة كل المحتوى بنفسك — **بدون أي حساب خارجي أو إعداد**.
قاعدة البيانات محلية (SQLite) وتتولّد وتُملأ تلقائيًا أول مرة تشغّل فيها
المشروع.

## 1. التشغيل (بدون أي إعداد)

```bash
npm install
npm run dev
```

افتح `http://localhost:3000` — هتلاقي الموقع شغال بالمحتوى الحقيقي
(الكتابين، الكورس، الاستشارات) من غير أي خطوة إضافية.

## 2. لوحة التحكم

```
http://localhost:3000/ar/admin/login
```

حساب أدمن افتراضي جاهز من أول تشغيل:

- **البريد**: `admin@clipmaster.se`
- **كلمة المرور**: `ClipMaster2026!`

⚠️ **غيّرهم فورًا** بعد أول دخول — إما بتعديل `ADMIN_EMAIL`/`ADMIN_PASSWORD` في
`.env.local` (انسخه من `.env.example` أولاً) ثم إعادة تشغيل المشروع، أو بحذف
المستخدم من قاعدة البيانات وإعادة تشغيل المشروع ليُنشئ واحدًا جديدًا بنفس
المتغيرات.

من لوحة التحكم تقدر تضيف/تعدّل/تحذف: المنتجات، الدورات، خدمات الاستشارات،
آراء العملاء، وتشوف كل الطلبات — كل ده بدون لمس الكود.

لكل منتج/دورة، لو سبته **بدون** رابط خارجي، هيتباع من خلال متجرنا مباشرة
(سلة + Stripe + تحميل آمن). لو حطيت رابط خارجي (مثلاً صفحة على Payhip)،
الزرار هيوديك هناك بدل كده.

## 3. التسليم الرقمي للمنتجات المباعة من عندنا

1. ضع الملف (PDF/ZIP) داخل مجلد `private/digital-products/` على السيرفر
   (هذا المجلد غير مرفوع على GitHub عمدًا — الملفات الحقيقية تُنقل يدويًا).
2. في صفحة المنتج بلوحة التحكم، اكتب اسم الملف في `file_path` (مثلاً
   `ebook.pdf`).
3. بعد الدفع، الموقع يتأكد من Stripe إن الدفع تم فعليًا، يحدّث حالة الطلب،
   ويولّد رابط تحميل موقّع رقميًا (HMAC) صالح لمدة 24 ساعة بس.

## 4. تفعيل الدفع الحقيقي عبر Stripe

انسخ `.env.example` إلى `.env.local` وحط مفاتيحك من
[dashboard.stripe.com/apikeys](https://dashboard.stripe.com/apikeys).

لتأكيد الدفع بشكل موثوق (ضروري):

```bash
stripe listen --forward-to localhost:3000/api/webhooks/stripe
```

هيديك `whsec_...` — حطه في `STRIPE_WEBHOOK_SECRET`. بعد النشر الحقيقي، أضف
Endpoint من dashboard.stripe.com/webhooks يشاور على:
`https://your-domain.com/api/webhooks/stripe` مع حدث `checkout.session.completed`.

## 5. حسابات العملاء

العميل يقدر يعمل حساب من `/ar/account/register`، وبعدها كل طلباته (اللي
اتعملت وهو داخل بحسابه) تظهر في `/ar/account`.

## 6. النشر (Deploy)

المشروع سيرفر Node عادي (مش ثابت/static)، يحتاج قرص دائم يحتفظ بملف
`data/clipmaster.db` بين عمليات إعادة التشغيل (مثل VPS عادي، أو أي منصة
تدعم Persistent Disk). **لا يصلح** للنشر على منصات serverless بقرص مؤقت
(زي Vercel الافتراضي) لأن قاعدة البيانات والملفات هتتمسح بين الطلبات.

1. ارفع المشروع على السيرفر، شغّل `npm install && npm run build && npm start`.
2. أضف `.env.local` بمفاتيح Stripe الحقيقية ومتغيرات الأدمن.
3. أضف Stripe webhook الحقيقي (قسم 4) على نفس الدومين.

## 7. ملاحظات أمان

- غيّر `ADMIN_PASSWORD`, `DOWNLOAD_SECRET`, `SESSION_SECRET` لقيم حقيقية قبل
  أي نشر عام — القيم الافتراضية للتجربة المحلية فقط.
- كل الأسعار تُقرأ من قاعدة البيانات وقت الدفع، لا يُعتمد على أي سعر جاي من
  المتصفح.
- حالة "مدفوع" على الطلب لا تتغيّر إلا بعد تأكيد حقيقي من Stripe (عبر الـ
  webhook، ومن صفحة النجاح كاحتياط) — لا يوجد محاكاة لدفع ناجح.
- ملف قاعدة البيانات `data/clipmaster.db` وملفات `private/digital-products/`
  غير مرفوعين على GitHub عمدًا (فيهم بيانات العملاء والمنتجات الحقيقية).
